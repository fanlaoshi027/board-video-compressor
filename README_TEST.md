# 板书压缩器第一轮实测

目标：使用真实的 1920x1080 / 60fps、已经压缩过的白底黑字板书视频做基准测试。

## 建议测试

1. 固定 15 FPS + H.265 + 平衡
2. 普通智能 VFR + H.265 + 平衡
3. 板书自适应 VFR + H.265 + 平衡
4. 板书自适应 VFR + 极限压缩
5. 板书自适应 VFR + 智能反色

每个结果记录：文件大小、平均码率、输出分辨率、实际帧率、时长、是否音画同步，以及快速书写/细字/彩色笔迹的清晰度。

## 依赖

```bash
python -m pip install -r requirements.txt
```

FFmpeg 仍需要单独安装并确保 `ffmpeg` 在 PATH 中。
