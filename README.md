# 樊老师板书视频压缩器

专门针对 **白底黑字数学板书 / 手写公式 / 网课录屏** 的 MP4 压缩工具。

目标不是单纯“把视频压小”，而是寻找板书视频的最佳压缩甜点区：

- 尽量保持数学公式、笔迹边缘清晰
- 尽量减少快速书写时的断裂、拖影和闪烁
- 优先测试 H.264 / H.265 / AV1
- 支持 1080p 30/60fps
- 后续加入批量处理和桌面 GUI

## 第一阶段

先用 FFmpeg 建立可重复的压缩测试流程。默认提供三档板书预设：

- `board-high`：高清，适合保存高质量网课版本
- `board-balanced`：清晰度 / 体积平衡，推荐首先测试
- `board-extreme`：极限压缩，用于寻找最小体积甜点区

## 使用

需要安装 FFmpeg，并确保 `ffmpeg`、`ffprobe` 在 PATH 中。

```bash
python compress.py input.mp4 --preset board-balanced --codec h265
```

查看所有参数：

```bash
python compress.py --help
```

Windows 也可以直接把 MP4 拖到 `run.bat`（后续 GUI 会替代这个方式）。

## 重要

本项目暂时**不追求漂亮界面**。第一目标是用真实的樊老师板书视频测试：

> 文件体积、文字清晰度、快速书写、公式边缘、手机观看效果。

确定最佳编码参数后，再开发桌面 GUI、批量队列、压缩前后对比和自动选择编码器。
